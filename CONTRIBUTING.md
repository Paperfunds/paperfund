# Contributing

Use Node.js 22+ and npm 10+. Follow the local setup in README.md with disposable services and synthetic users. Describe behavior changes and focused validation in your pull request. Original contributions are submitted under Apache-2.0. Identify third-party material and preserve its licenses and notices. Branding requires separate permission.

Preserve integer financial arithmetic, UTC windows, transactional admission, immutable ledgers, evidence validation, idempotency, STOP and authorization checks. Changes to economics or financial authority require explicit review. Keep signing, payouts, claims and fee ingestion disabled for local development.

Run `npm run build`, `npm run build:extension`, `npm run test:extension` and `npm run test:publication`. Integration and operational suites require explicit disposable infrastructure and sometimes historical release fixtures. Never substitute production services or credentials. Avoid a blanket full financial test run for routine source publication.

Keep generated builds, runtime profiles, logs, receipts, database backups and environment credentials out of contributions. See SECURITY.md for private vulnerability reporting.
